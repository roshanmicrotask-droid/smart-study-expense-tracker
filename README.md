# 📊 Smart Study & Expense Tracker (Python CLI)

A Command-Line Interface (CLI) project built in **Python 3** on Android (Pydroid 3) to track daily study sessions and personal expenses.

## 🚀 Key Features
- **Study Logger:** Record study topics, subjects, and time in minutes.
- **Expense Logger:** Track daily expenses by category and amount.
- **Instant Analytics:** Automatically calculates total study hours, total money spent, and unique categories.
- **File Storage:** Saves all records permanently in `data.txt`.

## 🧠 Python Concepts Practiced
- **OOP:** Classes, Objects, Constructors (`__init__`), Inheritance (`super()`), and Polymorphism
- **File Handling:** Reading (`r`) and Appending (`a`) local text files
- **Functional Programming:** `lambda`, `map()`, and List Comprehensions
- **Data Structures:** Lists, Dictionaries, Tuples, and Sets
- **Error Handling:** `try-except` blocks for safe user inputs
